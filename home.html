Ключевые возможности

🚀

Высокая производительность

Полностью асинхронная архитектура с двухуровневым кешированием (Redis + PostgreSQL) обеспечивает молниеносную обработку запросов.

🔗

Мульти-источники

Поддержка прямых конфигураций, внешних URL-подписок и внутренних ссылок с автоматическим рекурсивным разрешением.

🔒

Безопасность

HMAC-SHA256 подписи, IP whitelist, rate limiting, автоматическая блокировка и security headers из коробки.

⚡

Фоновые задачи

Celery workers автоматически обновляют внешние источники каждые 15 минут, обеспечивая актуальность данных.

📝

Кастомные комментарии

Добавляйте персональные комментарии к конфигурациям в каждой подписке независимо.

🛠️

Полный набор инструментов

REST API, Python библиотека, CLI утилита и Telegram бот - выбирайте удобный способ работы.
