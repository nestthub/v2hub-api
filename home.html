v2hub Ecosystem

VPN Subscription Management Platform

A modern VPN subscription management ecosystem with multi-source support, intelligent caching, automation tools, and a complete developer toolkit.

Python 3.11+ FastAPI PostgreSQL 16 Redis 7 Async REST API Docker Celery
Open Telegram Bot API Documentation

Key Features

🚀

High Performance

Fully asynchronous architecture with two-level caching (Redis + PostgreSQL) delivering fast and reliable request processing.

🔗

Multi-source Support

Support for direct configurations, external subscription URLs, and internal sources with automatic recursive resolution.

🔒

Security First

HMAC-SHA256 signatures, IP whitelisting, rate limiting, automatic banning, and security headers out of the box.

⚡

Background Automation

Celery workers automatically refresh external sources every 15 minutes, keeping subscription data always up to date.

📝

Custom Comments

Add personalized comments to generated configurations independently for each subscription.

🛠️

Complete Developer Toolkit

REST API, Python SDK, CLI tools, and Telegram bot integration — choose the workflow that fits your needs.
